# cardgamepriv — consignes pour les agents (Antigravity / Gemini)

TCG de collection privé (≈ 20-50 joueurs), mobile d'abord. Le code, git et la mise en ligne sont tenus par Claude
(Claude Code, règles dans CLAUDE.md). Gemini prépare des DONNÉES : listes, vérifications, images, sons, rapports.

Les règles détaillées sont dans `.agents/rules/` (périmètre, livrables, qualité) et les tâches toutes prêtes dans
`.agents/workflows/` (tape `/` dans le chat pour les voir).
