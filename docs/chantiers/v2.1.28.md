# Patch v2.1.28 — séquence GOD PACK sur le bon morceau d'un ×5 / ×10

- But : en ligne avant le 01/12 (God pack du 1er de la saison 0, souvent ouvert en ×10).
- Cause : `spreadSeries` (`src/game/views/shop.ts`) trie les cartes de la série (la meilleure à la fin) mais chaque morceau garde le drapeau `god` du vrai booster dont il porte l'id. Le God pack offert est le 1er scellé (`convex/packs.ts`) : dès qu'un autre booster du lot a aussi une 6★ (ou une secrète), il passe après lui → la séquence se joue sur un morceau ordinaire, les cartes du God pack arrivent plus tard sans elle.
- Correctif : `spreadSeries` sorti dans `src/game/series.ts` (fonction pure, testable). À meilleur tirage égal, un God pack est rangé (et crédité) après les autres ; le drapeau `god` va au DERNIER morceau seulement — ses cartes valent au moins celles du God pack (que des 4★+, une 5★ et une 6★). Une seule séquence par série.
- Fichiers : `src/game/series.ts` (nouveau), `src/game/views/shop.ts`, `src/game/updates.data.ts` + `updates.en.ts` (note).
- Schéma Convex : non. Rien dans `convex/` → pas de sauvegarde dans le lanceur. `packRoll` / `packRules` inchangés → pas de `test:rolls`.
- Risque : faible, visuel seulement (mêmes cartes, mêmes crédits). DA et animations 6★ inchangées (même séquence, seul le morceau change).
- Fini quand : typecheck + test:server verts ; check:i18n = 0 ; test ponctuel de `spreadSeries` (God pack 1er + autre 6★ / secrète / 2 God packs) → `god` sur le dernier morceau seulement, ses cartes = que des 4★+ avec 5★ et 6★.
