## 1.1. Chronologie Technique des Releases Three.js (r170 → r187 / 2025–2026)

### r170 à r178 : Consolidation de `three/webgpu` et `three/tsl`
- **Séparation claire des points d'entrée** dans `node_modules/three/package.json` :
  - `import * as THREE from 'three/webgpu'` (`src/Three.WebGPU.js`) expose `WebGPURenderer`, tous les `*NodeMaterial`, `RenderPipeline`, `DirectRenderPipeline`, `StorageTexture`, `Storage3DTexture`, `StorageArrayTexture`, `StorageBufferAttribute`, `StorageInstancedBufferAttribute`, `IndirectStorageBufferAttribute`, `ReadbackBuffer`, `BundleGroup`, etc.
  - `import { ... } from 'three/tsl'` (`src/Three.TSL.js` / `src/nodes/TSL.js`) expose l'intégralité du langage de shading orienté graphe de nœuds.
- **Fallback automatique WebGL 2** intégré à `WebGPURenderer` (`WebGPUBackend` + `WebGLBackend`), compilant le même graphe TSL en **WGSL** ou **GLSL ES 3.0**.
- **Parité complète des matériaux Node** : `MeshPhysicalNodeMaterial` (dispersion, iridescence, sheen, transmission, anisotropy, clearcoat), `SpriteNodeMaterial`, `PointsNodeMaterial`, `Line2NodeMaterial`, `VolumeNodeMaterial`.

### r179 à r182 : Stabilisation de l'API TSL & Rendu Synchrone
- **Fin de `renderAsync()` (déprécié en r181)** : Le pattern canonique moderne consiste à initialiser le renderer une seule fois via `await renderer.init()`, puis à appeler **`renderer.render(scene, camera)`** ou **`renderPipeline.render()`** de manière **100 % synchrone** dans `renderer.setAnimationLoop()`.
- **Renommages & Dépréciations TSL critiques** :
  - `.label('name')` → déprécié au profit de **`.setName('name')`** (`src/nodes/tsl/TSLBase.js`).
  - `cache(node)` → déprécié en r181 au profit de **`isolate(node)`** (`src/nodes/core/IsolateNode.js`).
  - `passNode.setResolution(scale)` → déprécié en r182 au profit de **`passNode.setResolutionScale(scale)`** (`src/nodes/display/PassNode.js`).
  - `instanceIndex` pour les compute shaders → déprécié en r179 au profit de **`globalId`** (`globalId.x`, `globalId.xy`, `globalId.xyz`) ou **`computeIndex`** (`src/nodes/tsl/TSLBase.js`).

### r183 : `RenderPipeline`, `DirectRenderPipeline`, `Timer` & `BatchedMesh` RGBA
- **`PostProcessing` renommé en `RenderPipeline`** (`src/renderers/common/RenderPipeline.js`).
- **Nouveau `DirectRenderPipeline`** (`src/renderers/common/DirectRenderPipeline.js`) : Alternative ultra-légère à `RenderPipeline` qui injecte le graphe de post-traitement (tone mapping, color grading, effets écran sans voisinage) **directement dans le fragment shader des matériaux** via `renderer.outputNode`, évitant la création d'un RenderTarget intermédiaire et d'un fullscreen quad !
- **`THREE.Clock` déprécié** au profit de `THREE.Timer`.
- **`BatchedMesh`** (`src/objects/BatchedMesh.js`) : Support de l'**opacité par instance** (`setColorAt(id, color, alpha)`) via une texture interne `RGBAFormat`, et support du mode `wireframe`.
- **Ombres** : Ajout de `shadow.biasNode` pour contrôler dynamiquement le shadow bias en TSL.

### r184 : Upscalers Temporels/Spatiaux (`TAAU` / `FSR1`) & `WebGLNodesHandler`
- **Upscaling natif TSL** :
  - **`FSR1Node`** (`examples/jsm/tsl/display/FSR1Node.js`) : AMD FidelityFX Super Resolution 1.0 (EASU 12-tap + RCAS).
  - **`TAAUNode`** (`examples/jsm/tsl/display/TAAUNode.js`) : Temporal Anti-Aliasing Upscaler avec Halton jittering, variance clipping YCoCg, et filtre Blackman-Harris.
- **`BatchedMesh` WebGPU** : Suppression de `multiDraw` sur WebGPU au profit de **`_VisibilityChanged` + fusion des plages d'indices contiguës (`mergedDraw`)**.

### r185 : Remplacement de `TiledLighting` par `ClusteredLighting` (Forward+ 3D) & WebXR
- **`TiledLighting` supprimé et remplacé par `ClusteredLighting` (`examples/jsm/lighting/ClusteredLighting.js`) et `ClusteredLightsNode` (`examples/jsm/tsl/lighting/ClusteredLightsNode.js`)** :
  - Découpe le frustum en **clusters 3D** ($X \times Y \times Z$ avec distribution logarithmique en profondeur `zNear`/`zFar`), évalué par un **Compute Shader** GPU + une `DataArrayTexture` d'indices compactés.
- **Séparation `positionLocal` vs `positionGeometry`** : Dans `material.positionNode`, `positionLocal` contient la position déjà transformée par le morphing/skinning/batching, tandis que `positionGeometry` est l'attribut brut du buffer.

### r186 : 3D Gaussian Splatting Natif, `SunLight` (CSM), `compileComputeAsync` & PBR EON
- **`GaussianSplat` (`examples/jsm/objects/GaussianSplat.js`) & `CountingSort` (`examples/jsm/gpgpu/CountingSort.js`)** : Implémentation officielle 100 % GPU (Compute Shaders TSL + Radix/Counting Sort en 4 passes 8-bit avec `workgroupArray` atomiques + évaluation des Harmoniques Sphériques degré 1 à 3 en compute).

### r187 (`0.187.0` — Version installée dans le projet) : Les Grandes Nouveautés

6. **Subgroup / Wave Intrinsics dans TSL (`src/nodes/gpgpu/SubgroupFunctionNode.js`)** & **Packed 4x8 Integer Dot Product (`src/nodes/math/Packed4x8IntegerNode.js`)** :

```js
// 1. Éclairage dynamique sans aucune recompilation shader (jusqu'à 16 lumières dynamiques)

const CardStateStruct = struct({
  position: 'vec3',
  manaCost: 'uint',
  rotation: 'vec4',
  foilIntensity: 'float'

const cardBuffer = instancedArray(128, CardStateStruct);

// 3. Matériau Maître unique + NodeMaterialInstance (0 compilation shader par carte) :
const masterCardMaterial = new MeshPhysicalNodeMaterial();
const cardArtTex = materialReference('artworkMap', 'texture');
const foilIntensity = materialReference('foilIntensity', 'float');
const manaGlowColor = materialReference('glowColor', 'color');

masterCardMaterial.colorNode = texture(cardArtTex, uv());
masterCardMaterial.emissiveNode = manaGlowColor.mul(foilIntensity);

const cardMat1 = new NodeMaterialInstance(masterCardMaterial);
cardMat1.artworkMap = dragonTexture;
cardMat1.foilIntensity = 0.85;
cardMat1.glowColor = new THREE.Color(0xff4400);

// 4. Compute Shader avec mémoire partagée L1 atomique (workgroupArray) :
const localHistogram = workgroupArray('uint', 256).toAtomic();
const computePass = Fn(() => {
  atomicStore(localHistogram.element(localId.x), uint(0));
  workgroupBarrier();
  const bin = globalId.x.bitAnd(uint(255));
  atomicAdd(localHistogram.element(bin), uint(1));
  workgroupBarrier();
})().computeKernel([256, 1, 1]);
```

## 2.1. Reverse-Engineering des Pipelines de Référence

### A. *Balatro* (LocalThunk — LÖVE2D / GLSL)
Chaque édition de carte (`foil.fs`, `holo.fs`, `polychrome.fs`, `negative.fs`, `gold_seal.fs`, `vortex.fs`) est un fragment shader procédural qui n'utilise **aucune texture de bruit lourde**, mais des distorsions trigonométriques itératives pilotées par l'inclinaison de la carte (`hovering` / `tilt_angle`) et le temps :
- **Distorsion de champ implicite (*Domain Warping* trigonométrique)** :
  $$\mathbf{p}_{k+1} = \mathbf{p}_k + \alpha \begin{pmatrix} \sin(\omega_k p_{k,y} + t + \theta_{\text{tilt},x}) \\ \cos(\omega_k p_{k,x} - t + \theta_{\text{tilt},y}) \end{pmatrix}$$
- **Polychrome (`polychrome.fs`)** : Convertit le texel de base en espace **HSL**, puis fait tourner la teinte ($H$) selon la phase du champ déformé et l'angle d'inclinaison :
  $$H_{\text{out}} = \text{fract}\big(H_{\text{in}} + 0.35 \sin(\mathbf{u} \cdot \mathbf{k} + t) + \Delta_{\text{tilt}}\big)$$
  tout en poussant la saturation $S \to \min(1.0, S \times 1.3)$ et en ajoutant un reflet spéculaire irisé.
- **Negative (`negative.fs`)** : Inversion dans l'espace HSL avec rotation de phase suivie d'un ancrage colorimétrique sarcelle sombre :
  1. Conversion $\text{RGB} \to \text{HSL}(H, S, L)$.
  2. Inversion de la luminosité : $L' = 1.0 - L$.
  3. Symétrie + décalage de teinte : $H' = \text{fract}(-H + 0.2)$.
  4. Conversion $\text{HSL}(H', S, L') \to \text{RGB}'$, puis addition d'un vecteur d'ambiance signature `(79, 99, 103) / 255`.

### B. *Pokémon TCG Pocket* & `pokemon-cards-css` (Simon Goellner)
- **Cartes Immersives & Parallaxe Multi-Plans (Stencil Windowing)** : 3 à 5 plans 3D (ou couches UV décalées en $Z < 0$) s'échelonnent en profondeur : ciel/fond ($z = -0.15$), décor moyen ($z = -0.08$), sujet principal ($z = -0.02$), effets d'avant-plan ($z = +0.02$).
- **Etched Foil (Gravure Texturée / Empreinte Digitale des cartes SAR)** : Micro-relief de lignes topographiques ou concentriques autour du personnage. La lumière glisse le long de ces sillons par réflexion anisotrope (Kajiya-Kay).
- **Glitter / Paillettes Cellulaires (Gold Star / Shiny)** : Pavage de Voronoï microscopique où chaque cellule possède une normale aléatoire fixe. Quand la carte tourne, les cellules dont la normale s'aligne avec le demi-vecteur $\mathbf{H} = \text{normalize}(\mathbf{L} + \mathbf{V})$ s'allument violemment puis s'éteignent en quelques degrés de rotation.

### C. *Marvel Snap* (Frame Break 3D + Ombre Portée sur la Bordure)
- Dès le palier *Frame Break*, la couche du sujet principal détouré (`subjectAlpha`) **ignore le masque de rognage de la fenêtre**, subit un léger grandissement ($\text{scale} \approx 1.06$) et une élévation virtuelle $\Delta z > 0$, et surtout **projette une ombre portée douce (`dropShadow`) directement sur la bordure métallique de la carte** en décalant l'alpha du sujet dans la direction opposée à la lumière :
  $$S_{\text{border}}(\mathbf{u}) = 1.0 - \alpha_{\text{shadow}} \cdot \text{smoothstep}\big(0.0, 1.0, \text{Tex}_{\text{subject}}(\mathbf{u} - \gamma \mathbf{L}_{xy}).a\big)$$

### D. *Gwent* & *Hearthstone* (Dual-Phase Flowmap Distortion)
- Pour animer le feu, l'eau, la fumée ou l'aura énergétique sans étirement infini de texture, un vecteur de flux 2D $\mathbf{F}(\mathbf{u})$ déforme les UVs sur deux phases décalées d'un demi-cycle :
  $$\phi_0 = \text{fract}(t), \quad \phi_1 = \text{fract}(t + 0.5), \quad w = 2.0 \,|\,0.5 - \phi_0\,|$$
  $$\mathbf{C}_{\text{flow}} = \text{mix}\big(\text{Tex}(\mathbf{u} - \mathbf{F}(\mathbf{u})\phi_0),\; \text{Tex}(\mathbf{u} - \mathbf{F}(\mathbf{u})\phi_1),\; w\big)$$

## 2.2. Module Shader GLSL Complet & Fonctions TSL (`three/tsl`)

```glsl
// ============================================================================
// MASTER TCG SHADER — GLSL FRAGMENT MODULE (Diffraction, Thin-Film, Voronoï,
// Balatro Polychrome/Negative, Etched Foil, POM 2.5D & Frame Break Shadow)
// ============================================================================
precision highp float;

varying vec2 vUv;
varying vec3 vWorldNormal;
varying vec3 vWorldPosition;
varying vec3 vTangent;
varying vec3 vBitangent;

uniform float uTime;
uniform vec2  uTilt;          // Inclinaison normalisée [-1, 1] (souris / gyroscope)
uniform float uRarityTier;    // 0.0 (Commune) -> 6.0 (Secrète Bébou)

uniform sampler2D uBaseArtTex;
uniform sampler2D uSubjectTex;
uniform sampler2D uDepthMap;  // R: Depth, G: FoilMask, B: InsideWindowMask
uniform sampler2D uFrameTex;

vec2 hash22(vec2 p) {
    p = vec2(dot(p, vec2(127.1, 311.7)), dot(p, vec2(269.5, 183.3)));
    return fract(sin(p) * 43758.5453123);
}

vec4 voronoiGlitter(vec2 uv, float scale) {
    vec2 p = uv * scale;
    vec2 n = floor(p);
    vec2 f = fract(p);
    float f1 = 8.0;
    float f2 = 8.0;
    vec2 bestCell = vec2(0.0);
    for (int j = -1; j <= 1; j++) {
        for (int i = -1; i <= 1; i++) {
            vec2 g = vec2(float(i), float(j));
            vec2 o = hash22(n + g);
            vec2 r = g + o - f;
            float d = dot(r, r);
            if (d < f1) { f2 = f1; f1 = d; bestCell = n + g; }
            else if (d < f2) { f2 = d; }
        }
    }
    vec2 cid = hash22(bestCell);
    return vec4(sqrt(f1), sqrt(f2), cid.x, cid.y);
}

vec3 bump3y(vec3 x, vec3 yoffset) {
    vec3 y = vec3(1.0) - x * x;
    return clamp(y - yoffset, 0.0, 1.0);
}

vec3 spectralZucconi6(float x) {
    x = fract(x);
    const vec3 c1 = vec3(3.54585104, 2.93225262, 2.41593945);
    const vec3 x1 = vec3(0.69549072, 0.49228336, 0.27699880);
    const vec3 y1 = vec3(0.02312639, 0.15225084, 0.52607955);
    const vec3 c2 = vec3(3.90307140, 3.21182957, 3.96587128);
    const vec3 x2 = vec3(0.11748627, 0.86755042, 0.66077860);
    const vec3 y2 = vec3(0.84897130, 0.88445281, 0.73949448);
    return bump3y(c1 * (x - x1), y1) + bump3y(c2 * (x - x2), y2);
}

vec3 thinFilmIridescence(float cosThetaV, float dNanometers, float iorFilm) {
    float sinThetaT2 = (1.0 - cosThetaV * cosThetaV) / (iorFilm * iorFilm);
    float cosThetaT = sqrt(max(0.0, 1.0 - sinThetaT2));
    float opd = 2.0 * iorFilm * dNanometers * cosThetaT;
    vec3 lambdas = vec3(650.0, 510.0, 440.0);
    return 0.5 + 0.5 * cos(6.2831853 * opd / lambdas + vec3(0.0, 0.5, 1.0));
}

vec3 applyBalatroPolychrome(vec3 rgb, vec2 uv, vec2 tilt, float time) {
    vec2 p = uv * 4.0;
    for (int i = 0; i < 3; i++) {
        p += 0.35 * vec2(
            sin(p.y * 2.2 + time * 1.1 + tilt.x * 3.0),
            cos(p.x * 2.2 - time * 0.9 + tilt.y * 3.0)
        );
    }
    float wave = 0.5 + 0.5 * sin(p.x + p.y);
    vec3 polySpectrum = spectralZucconi6(wave + dot(tilt, vec2(0.4, 0.4)));
    return mix(rgb, rgb * (0.65 + 0.95 * polySpectrum) + polySpectrum * 0.22, 0.65);
}

vec2 computeEtchedGradient(vec2 uv, vec2 focalCenter) {
    vec2 d = uv - focalCenter;
    float r = length(d) + 1e-4;
    float angle = atan(d.y, d.x);
    float freq = 140.0;
    float phase = r * freq + 3.5 * sin(angle * 6.0 + r * 20.0);
    float dPhaseDr = freq * cos(phase);
    return (d / r) * dPhaseDr * 0.008;
}
```

```javascript
import {
  Fn, uniform, uv, vec2, vec3, vec4, float,
  sin, cos, abs, fract, floor, dot, length, sqrt, pow,
  min, max, clamp, mix, step, smoothstep, normalize
} from 'three/tsl';

export const spectralZucconi6TSL = Fn(([x_in]) => {
  const x = fract(x_in);
  const c1 = vec3(3.54585104, 2.93225262, 2.41593945);
  const x1 = vec3(0.69549072, 0.49228336, 0.27699880);
  const y1 = vec3(0.02312639, 0.15225084, 0.52607955);
  const c2 = vec3(3.90307140, 3.21182957, 3.96587128);
  const x2 = vec3(0.11748627, 0.86755042, 0.66077860);
  const y2 = vec3(0.84897130, 0.88445281, 0.73949448);

  const d1 = c1.mul(x.sub(x1));
  const d2 = c2.mul(x.sub(x2));
  const b1 = clamp(vec3(1.0).sub(d1.mul(d1)).sub(y1), 0.0, 1.0);
  const b2 = clamp(vec3(1.0).sub(d2.mul(d2)).sub(y2), 0.0, 1.0);
  return b1.add(b2);

export const cellularSparkleTSL = Fn(([uvNode, normalNode, viewDirNode, lightDirNode, densityScale]) => {
  const scaledUv = uvNode.mul(densityScale);
  const cellCoord = floor(scaledUv);
  const localUv = fract(scaledUv).sub(0.5);

  const h1 = fract(sin(dot(cellCoord, vec2(127.1, 311.7))).mul(43758.5453));
  const h2 = fract(sin(dot(cellCoord, vec2(269.5, 183.3))).mul(43758.5453));
  const h3 = fract(sin(dot(cellCoord, vec2(419.2, 371.9))).mul(43758.5453));

  const distToCenter = length(localUv.sub(vec2(h1, h2).sub(0.5).mul(0.5)));
  const flakeShape = smoothstep(0.42, 0.25, distToCenter);
  const sparsityMask = step(0.6, h3);

  const flakeNormal = normalize(normalNode.add(vec3(h1.sub(0.5), h2.sub(0.5), 0.0).mul(0.65)));
  const halfVec = normalize(viewDirNode.add(lightDirNode));
  const specFlash = pow(max(dot(flakeNormal, halfVec), 0.0), 400.0);

  const prismColor = spectralZucconi6TSL(h1.add(dot(halfVec, vec3(1.0, 0.5, 0.0)).mul(2.0)));
  return prismColor.mul(specFlash).mul(flakeShape).mul(sparsityMask).mul(10.0);
});

export const balatroPolychromeTSL = Fn(([baseColor, uvNode, tiltUniform, timeUniform]) => {
  const p0 = uvNode.mul(4.5);
  const p1 = p0.add(vec2(
    sin(p0.y.mul(2.0).add(timeUniform).add(tiltUniform.x.mul(3.0))),
    cos(p0.x.mul(2.0).sub(timeUniform).add(tiltUniform.y.mul(3.0)))
  ).mul(0.4));
  const p2 = p1.add(vec2(
    sin(p1.y.mul(3.1).sub(timeUniform.mul(0.7))),
    cos(p1.x.mul(3.1).add(timeUniform.mul(0.7)))
  ).mul(0.3));

  const phase = sin(p2.x.add(p2.y)).mul(0.5).add(0.5);
  const polyRGB = spectralZucconi6TSL(phase.add(tiltUniform.x.mul(0.5)));
  return mix(baseColor, baseColor.mul(polyRGB.add(0.5)).add(polyRGB.mul(0.25)), 0.65);
});
```

```javascript
import { Fn, vec2, vec3, vec4, float, length, normalize, smoothstep, sin, uniform, viewportResolution } from 'three/tsl';

export const shockCenter   = uniform(new THREE.Vector2(0.5, 0.5));
export const shockRadius   = uniform(0.0);
export const shockWidth    = uniform(0.12);
export const shockStrength = uniform(0.06);
export const shockChroma   = uniform(0.015);

export const applyShockwave = Fn(([inputTexNode, uv]) => {
  const aspect = viewportResolution.x.div(viewportResolution.y);
  const delta = uv.sub(shockCenter);
  const dist = length(vec2(delta.x.mul(aspect), delta.y));
  const dir = normalize(delta.add(vec2(1e-6)));

  const diff = dist.sub(shockRadius);
  const mask = smoothstep(shockWidth.negate(), float(0.0), diff)
    .mul(float(1.0).sub(smoothstep(float(0.0), shockWidth, diff)));
  const wave = sin(diff.div(shockWidth).mul(3.14159265)).mul(mask).mul(shockStrength);

  const r = inputTexNode.sample(uv.add(dir.mul(wave.add(mask.mul(shockChroma))))).r;
  const g = inputTexNode.sample(uv.add(dir.mul(wave))).g;
  const b = inputTexNode.sample(uv.add(dir.mul(wave.sub(mask.mul(shockChroma))))).b;
  const a = inputTexNode.sample(uv.add(dir.mul(wave))).a;
  return vec4(r, g, b, a);
});
```

## 4.1. Simulation de Film Plastique / Aluminium & Déchirure de Booster (XPBD / Verlet en TSL)

```javascript
import * as THREE from 'three/webgpu';
import {
  Fn, instancedArray, instanceIndex, uniform, float, vec3, vec4,
  If, length
} from 'three/tsl';

const GRID_W = 64;
const GRID_H = 96;
const NUM_VERTS = GRID_W * GRID_H;

const posArray = instancedArray(NUM_VERTS, 'vec4');
const prevPosArray = instancedArray(NUM_VERTS, 'vec4');
// x: lien droit actif (1 ou 0), y: lien bas actif (1 ou 0), z: cisaillement, w: seuil de rupture local
const constraintState = instancedArray(NUM_VERTS, 'vec4');

const uFingerPos = uniform(new THREE.Vector3());
const uFingerDelta = uniform(new THREE.Vector3());
const uGrabRadius = uniform(0.35);
const uRestDist = uniform(0.05);

// PASSE 1 : Intégration de Verlet + Interaction du doigt
const integrateBoosterCompute = Fn(() => {
  const idx = instanceIndex;
  const pData = posArray.element(idx).toVar();
  const prevData = prevPosArray.element(idx).toVar();
  const invMass = pData.w;

  If(invMass.greaterThan(0.0), () => {
    const pos = pData.xyz.toVar();
    const prev = prevData.xyz.toVar();
    const vel = pos.sub(prev).mul(0.985);
    prevPosArray.element(idx).assign(vec4(pos, prevData.w));

    const distToFinger = length(pos.sub(uFingerPos));
    If(distToFinger.lessThan(uGrabRadius), () => {
      const influence = float(1.0).sub(distToFinger.div(uGrabRadius)).pow(2.0);
      pos.addAssign(uFingerDelta.mul(influence));
    });

    pos.addAssign(vel);
    posArray.element(idx).assign(vec4(pos, invMass));
  });
})().compute(NUM_VERTS, [64]);

// PASSE 2 : Relaxation des contraintes de distance XPBD & Déchirure sur la ligne d'encoche
const solveConstraintsAndTearCompute = Fn(() => {
  const idx = instanceIndex;
  const x = idx.mod(GRID_W);
  const y = idx.div(GRID_W);

  const pA = posArray.element(idx).toVar();
  const state = constraintState.element(idx).toVar();
  const tearLimit = state.w; // 1.18 sur la ligne de découpe (y == 14), 3.5 ailleurs

  If(x.lessThan(GRID_W - 1).and(state.x.greaterThan(0.5)), () => {
    const rightIdx = idx.add(1);
    const pB = posArray.element(rightIdx).toVar();
    const delta = pB.xyz.sub(pA.xyz);
    const dist = length(delta).max(1e-5);
    const stretch = dist.div(uRestDist);

    If(stretch.greaterThan(tearLimit), () => {
      state.x.assign(0.0);
    }).Else(() => {
      const diff = dist.sub(uRestDist).div(dist).mul(0.45);
      If(pA.w.greaterThan(0.0), () => { pA.xyz.addAssign(delta.mul(diff)); });
    });
  });

  If(y.lessThan(GRID_H - 1).and(state.y.greaterThan(0.5)), () => {
    const downIdx = idx.add(GRID_W);
    const pB = posArray.element(downIdx).toVar();
    const delta = pB.xyz.sub(pA.xyz);
    const dist = length(delta).max(1e-5);
    const stretch = dist.div(uRestDist);

    If(stretch.greaterThan(tearLimit), () => {
      state.y.assign(0.0);
    }).Else(() => {
      const diff = dist.sub(uRestDist).div(dist).mul(0.45);
      If(pA.w.greaterThan(0.0), () => { pA.xyz.addAssign(delta.mul(diff)); });
    });
  });

  posArray.element(idx).assign(pA);
  constraintState.element(idx).assign(state);
})().compute(NUM_VERTS, [64]);
```

## 4.2. Déformation Physique de Carte : Card Peeling / Corner Bend ("Sweat Reveal") en TSL

```javascript
import * as THREE from 'three/webgpu';
import {
  Fn, uniform, vec2, vec3, float, positionLocal, normalLocal, uv,
  frontFacing, dot, sin, cos, smoothstep, select, If, PI
} from 'three/tsl';

const uFoldPoint  = uniform(new THREE.Vector2(0.65, -0.95));
const uFoldDir    = uniform(new THREE.Vector2(0.707, -0.707));
const uCurlRadius = uniform(0.24);

const computeCardPeel = Fn(() => {
  const pos = positionLocal.toVar();
  const norm = normalLocal.toVar();
  const relPos = pos.xy.sub(uFoldPoint);
  const d = dot(relPos, uFoldDir);
  const R = uCurlRadius;
  const halfCircumference = PI.mul(R);

  If(d.greaterThan(0.0), () => {
    const baseXY = pos.xy.sub(uFoldDir.mul(d));
    If(d.lessThanEqual(halfCircumference), () => {
      const theta = d.div(R);
      const sinT = sin(theta);
      const cosT = cos(theta);
      const newXY = baseXY.add(uFoldDir.mul(R.mul(sinT)));
      const newZ = R.mul(float(1.0).sub(cosT));
      pos.assign(vec3(newXY.x, newXY.y, newZ));
      norm.assign(vec3(uFoldDir.x.negate().mul(sinT), uFoldDir.y.negate().mul(sinT), cosT));
    }).Else(() => {
      const overhang = d.sub(halfCircumference);
      const sag = overhang.pow(2.0).mul(0.08);
      const newXY = baseXY.sub(uFoldDir.mul(overhang));
      const newZ = R.mul(2.0).sub(sag);
      pos.assign(vec3(newXY.x, newXY.y, newZ));
      norm.assign(vec3(0.0, 0.0, -1.0));
    });
  });
  return { pos, norm, d };
});
```

## 4.3. Rendu des 1 025 Pokémon en 1 Seul Draw Call (`BatchedMesh` Multi-LOD + `CompressedArrayTexture` KTX2)

- **Problème VRAM** : 1 025 textures RGBA8 non compressées en $1024 \times 1428 \approx \mathbf{8.0 \text{ Go de VRAM}}$ (crash sur mobile).
- **Solution** :
  - On packe **16 cartes ($4 \times 4$ grille d'atlas)** par couche de $1024 \times 1424$ dans une `CompressedArrayTexture` KTX2 (BC7/ASTC/ETC2) : $\lceil 1025 / 16 \rceil = \mathbf{65\text{ couches}}$ seulement (< limite WebGPU mobile de 256 couches) = **~62 Mo de VRAM au total**.
  - On combine avec un unique `THREE.BatchedMesh` enregistrant 3 géométries de LOD (`LOD0` $24 \times 32$, `LOD1` $4 \times 6$, `LOD2` $1 \times 1$) : **1 seul Draw Call pour les 1 025 Pokémon**.

### B. Retour Haptique iPhone (iOS Safari 17.4+ / iOS 18) : `src/core/haptics.ts`
- `navigator.vibrate` n'existe pas sur iOS Safari. Depuis Safari 17.4 / iOS 18, un `<input type="checkbox" switch>` caché dont on clique le `<label for="...">` associé déclenche nativement le **Taptic Engine** d'iOS :

```ts
// src/core/haptics.ts
class Haptics {
  private label: HTMLLabelElement | null = null;
  private timers: number[] = [];

  private ensureIOSNode() {
    if (this.label || typeof document === 'undefined') return;
    const wrap = document.createElement('div');
    wrap.style.cssText = 'position:fixed;top:-99px;left:-99px;width:1px;height:1px;opacity:0;pointer-events:none;overflow:hidden';
    const inp = document.createElement('input');
    inp.type = 'checkbox';
    inp.id = 'bebou-haptic-switch';
    inp.setAttribute('switch', '');
    const lbl = document.createElement('label');
    lbl.htmlFor = 'bebou-haptic-switch';
    wrap.append(inp, lbl);
    document.body.append(wrap);
    this.label = lbl;
  }

  pulse(pattern: number | number[] = 25) {
    this.timers.forEach((id) => clearTimeout(id));
    this.timers = [];
    try {
      if (typeof navigator !== 'undefined' && typeof navigator.vibrate === 'function') {
        navigator.vibrate(pattern);
        return;
      }
      this.ensureIOSNode();
      if (!this.label) return;
      if (typeof pattern === 'number') {
        this.label.click();
      } else {
        let t = 0;
        for (let i = 0; i < pattern.length; i += 2) {
          const delay = t;
          this.timers.push(window.setTimeout(() => this.label?.click(), delay));
          t += pattern[i] + (pattern[i + 1] ?? 0);
        }
      }
    } catch {
      /* ignore */
    }
  }
}
export const haptics = new Haptics();
```
